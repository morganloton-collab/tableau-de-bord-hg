# Tableau de bord HG

Tableau de bord personnel pour l'enseignement de l'Histoire-Géographie-EMC.

## Publication avec GitHub Pages

1. Créer un dépôt GitHub nommé `tableau-de-bord-hg`.
2. Importer tous les fichiers de ce dossier à la racine du dépôt.
3. Aller dans **Settings → Pages**.
4. Dans **Build and deployment**, choisir **Deploy from a branch**.
5. Sélectionner la branche `main` et le dossier `/ (root)`.
6. Cliquer sur **Save**.
7. L'adresse sera de la forme :
   `https://VOTRE-PSEUDO.github.io/tableau-de-bord-hg/`

Le site fonctionne sans serveur : les données personnalisées sont enregistrées dans le navigateur avec localStorage.
